# 1.0.10：CTF 视图重排与刷新状态保留

发布日期：2026-09-30

这个版本处理的是顶部 CTF 视图的可读性和轮询干扰：首屏只突出最常用入口，低频页面仍保留；数据刷新时不再把用户正在查看的报告或 Agent 任务收回。

## 主要变化

- 题目看板、Agent 活动、环境和报告进入主导航；理论题、协同通信、提交审计从「更多视图」进入，原 view id 与接口保持不变。
- 赛事名称、进度指标和六项统计合并到一张摘要卡，统计格在窄屏自动改为两列；导航按钮有明确焦点样式和 40px 触达高度。
- 报告与 Agent 任务使用稳定标识保存原生 `details` 展开状态，报告正文滚动位置在轮询重绘后恢复；当前低频视图激活时「更多视图」不会被收起。
