# 1.0.8：多会话隔离与请求边界

这个版本集中处理并行会话的数据归属、平台请求边界和本地状态写入。

## 主要变化

- 团队、状态、报告和 token 用量都按 DSH session ID 读取，不再共用一个最近会话槽位。
- 页面切换会话后会取消旧请求，晚到的旧响应不能覆盖当前内容。
- 平台写请求默认不重试；附件限额为 64 MiB，使用流式正文超时、临时文件和原子落盘。
- 平台跳转只允许同源，普通响应体最大 32 MiB；异常 HTTP 响应不会被保存成附件。
- 本地状态采用进程间锁、唯一临时文件和合并写入，并保持 `0700/0600` 权限。
- 配置写入拒绝跨站来源，HTTP 响应不再泄露本机绝对路径。
- AWD/CFS 能力使用版本化三态合同，状态未知时执行前重新确认。
- 平台题面和理论题内容明确按不可信数据处理。
